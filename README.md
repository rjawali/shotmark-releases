# ShotMark

A native macOS screenshot and markup app for Kantiv.

## Download

[Download the latest release](https://github.com/rjawali/shotmark-releases/releases/latest).
Choose the `.dmg` file, open it, and drag ShotMark into Applications. Launch the
app and follow Capture Setup to enable Screen Recording.

Requires macOS 13 or later. Installers include Apple Silicon and Intel binaries.
Releases are signed with Joist Technologies Inc.’s Developer ID and notarized by Apple.

## Updates

ShotMark 2.8 and later check for signed updates automatically. Control checks and
installation on quit in Settings > Updates, or choose ShotMark > Check for Updates.
People using 2.7 must install 2.8 once to enable future in-app updates.

This repository hosts public installers and the signed Sparkle feed. The
application source is maintained separately in a private repository.
